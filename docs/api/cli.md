# CLI - Интерфейс командной строки

Модуль CLI предоставляет интерфейс командной строки для пакета mgimo.

## Обзор

После установки пакета становится доступна команда `mgimo`, которая предоставляет доступ к различным утилитам через терминал.

## Использование

### Справка

Показать справку по использованию:

```bash
mgimo --help
```

Вывод:

```
MGIMO command line magic and datasets.

Usage:
  mgimo quiz [--capitals=n] [--countries=k]
  mgimo --version
  mgimo --help

Options:
  -h --help       Show this screen
  --version       Show version
```

### Версия

Показать версию пакета:

```bash
mgimo --version
```

Вывод:

```
0.5.0
```

## Команды

### quiz - Тест по столицам

Запустить интерактивный тест на знание столиц мира.

#### Базовое использование

```bash
mgimo quiz
```

По умолчанию задает 2 вопроса о столицах и 2 вопроса о странах.

#### Параметры

**--capitals=n**

Количество вопросов, где дается столица и нужно выбрать страну.

Пример:

```bash
mgimo quiz --capitals=10
```

**--countries=k**

Количество вопросов, где дается страна и нужно выбрать столицу.

Пример:

```bash
mgimo quiz --countries=5
```

#### Примеры

Только вопросы о столицах (10 вопросов):

```bash
mgimo quiz --capitals=10 --countries=0
```

Только вопросы о странах (8 вопросов):

```bash
mgimo quiz --capitals=0 --countries=8
```

Смешанный тест:

```bash
mgimo quiz --capitals=5 --countries=5
```

## Реализация

CLI использует библиотеку [docopt](http://docopt.org/) для парсинга аргументов командной строки.

### Точка входа

В `pyproject.toml` определена точка входа:

```toml
[project.scripts]
mgimo = "mgimo.cli:main"
```

Это означает, что команда `mgimo` вызывает функцию `main()` из модуля `mgimo.cli`.
