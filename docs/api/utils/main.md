# Основные функции

Модуль с основными утилитами пакета.

## Обзор

Этот модуль содержит базовые функции, используемые в пакете mgimo.

## Примеры использования

### Функция hello

```python
from mgimo import hello

# Вызвать функцию
result = hello()
print(result)  # "MGIMO finished"
```

Эта функция является примером простой утилиты и может использоваться для проверки работоспособности импорта пакета.
