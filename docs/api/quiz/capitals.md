# Квиз: Столицы мира

Модуль для проведения теста на знание столиц стран мира.

## Обзор

Этот модуль реализует интерактивную игру-тест, где пользователь отвечает на вопросы о столицах стран. Тест можно запустить несколько раз с различными параметрами.

## Типы вопросов

1. **По столице** - дается название столицы, нужно выбрать страну
2. **По стране** - дается название страны, нужно выбрать столицу

## Примеры использования

### Запуск теста из командной строки

```bash
# Запустить стандартный тест (2 вопроса о столицах + 2 о странах)
mgimo quiz

# Настроить количество вопросов
mgimo quiz --capitals=5 --countries=10

# Только вопросы о столицах
mgimo quiz --capitals=10 --countries=0
```

### Использование в коде

```python
from mgimo.quiz.capitals import run

# Запустить тест с параметрами
run(n_capitals=3, n_countries=3)
```

### Пользовательский квиз с отдельными вопросами

```python
from mgimo.quiz.capitals import ask_about_capital, ask_about_country

# Спросить про конкретную страну
result = ask_about_capital("Россия")
if result:
    print("Правильно!")

# Спросить про конкретную столицу
result = ask_about_country("Токио")
if result:
    print("Верно!")
```

### Работа с данными стран и столиц

```python
from mgimo.quiz.capitals import city_dict
from mgimo.dataset.data import country_to_capital

# Словарь страна -> столица
print(country_to_capital["Франция"])  # "Париж"

# Словарь столица -> страна
print(city_dict["Берлин"])  # "Германия"
```

## Функции модуля

### ask_user

Базовая функция для задания вопроса с вариантами ответа.

**Параметры:**
- `question` (str) - текст вопроса
- `correct` (str) - правильный ответ
- `incorrect` (list[str]) - список неправильных вариантов

**Возвращает:**
- `bool` - True если ответ правильный, False в противном случае

### ask_about_capital

Спросить пользователя о стране по названию столицы.

**Параметры:**
- `country` (str) - название страны
- `n` (int) - количество вариантов ответа (по умолчанию 4)

**Возвращает:**
- `bool` - результат ответа

### ask_about_country

Спросить пользователя о столице по названию страны.

**Параметры:**
- `city` (str) - название столицы
- `n` (int) - количество вариантов ответа (по умолчанию 4)

**Возвращает:**
- `bool` - результат ответа

### run

Запустить полный тест.

**Параметры:**
- `n_capitals` (int) - количество вопросов о столицах (по умолчанию 2)
- `n_countries` (int) - количество вопросов о странах (по умолчанию 2)
