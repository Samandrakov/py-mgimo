# Установка

## Установка через pip

Самый простой способ установки - через pip:

```bash
pip install mgimo
```

После установки в командной строке станет доступна утилита `mgimo`, а для использования в других программах - одноименная библиотека.

## Проверка установки

Проверить запуск утилиты:

```bash
mgimo --help
```

Вы должны увидеть справку по использованию команды.

## Установка для разработки

Если вы хотите внести вклад в разработку пакета, используйте [пакетный менеджер `uv`](https://github.com/astral-sh/uv):

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/mgimo-dd/py-mgimo.git
cd py-mgimo
```

### 2. Установите зависимости

```bash
uv sync
```

### 3. Запустите CLI в режиме разработки

```bash
uv run mgimo
```

## Требования

- Python >= 3.10
- docopt >= 0.6.2
- pandas >= 2.3.3

## Установка конкретной версии

Для установки конкретной версии используйте:

```bash
pip install mgimo==0.5.0
```

## Сборка из исходников

Если вы хотите собрать пакет из исходников:

### 1. Соберите образ пакета

```bash
uv build
```

### 2. Установите образ через pip

```bash
pip install dist/mgimo-0.5.0-py3-none-any.whl
```

## Обновление

Для обновления до последней версии:

```bash
pip install --upgrade mgimo
```

## Удаление

Для удаления пакета:

```bash
pip uninstall mgimo
```

## Проблемы при установке

Если у вас возникли проблемы при установке, пожалуйста:

1. Убедитесь, что у вас установлена подходящая версия Python (>= 3.10)
2. Попробуйте обновить pip: `pip install --upgrade pip`
3. Откройте [issue на GitHub](https://github.com/mgimo-dd/py-mgimo/issues) с описанием проблемы
