# MGIMO Python Package

Добро пожаловать в документацию пакета **mgimo** - программных утилит и данных МГИМО.

## Описание

`mgimo` - это Python пакет, который предоставляет:

- 🎯 **Утилиты для оценки**: конвертация оценок в шкале МГИМО
- 🌍 **Обучающие игры**: тест на знание столиц мира
- 📊 **Наборы данных**: информация о странах и столицах мира
- 🛠️ **CLI инструменты**: интерфейс командной строки для быстрого доступа

## Быстрый старт

### Установка

```bash
pip install mgimo
```

### Использование CLI

Запустить тест на знание столиц:

```bash
mgimo quiz
```

Настроить количество вопросов:

```bash
mgimo quiz --countries=10 --capitals=5
```

### Использование как библиотека

```python
from mgimo.dataset.data import country_to_capital
from mgimo.utils.grading import convert_to_letter

# Получить столицу
capital = country_to_capital["Россия"]
print(f"Столица России: {capital}")  # Москва

# Конвертировать оценку
grade = convert_to_letter(85)
print(f"Оценка 85 баллов = {grade}")  # B
```
